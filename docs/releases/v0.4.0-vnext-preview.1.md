## Public Boundary

This prerelease remains:

- mock-only;
- in-memory;
- single-process;
- canonical demo only;
- no real side effects;
- no persistence;
- no production Runtime Adapter;
- no real customer adapters;
- no real LLM / RAG / knowledge base;
- not production ready.

It does not contain real credentials, private customer data, or production
adapter configuration.

## Known Limitations

- No distributed execution.
- No Snapshot / Resume.
- No Cancellation.
- No persistent Evidence or Audit store.
- No arbitrary Scenario Plan Authoring.
- No real system integration.
- npm packages are not published.

## Publication State

The annotated Tag and non-draft GitHub prerelease are published. npm packages
remain unpublished and production use remains out of scope.
