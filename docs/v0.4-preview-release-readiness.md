## Release Scope

The v0.4 Preview candidate includes:

1. Scenario Pattern Core.
2. Scenario Composition Contract, Compiler, and Studio Compile Preview.
3. Scenario Orchestrator Contract, Compiler, and Studio Preview.
4. Scenario Orchestrator Runtime Adapter Contract.
5. In-memory Demo Runtime Adapter for isolated Slot execution.
6. Explicit Slot Outcome Projection contracts and evidence.
7. Dispatch-time side-effect enforcement with fail-closed classification.
8. In-memory Scenario Orchestrator Engine for canonical demos.
9. Studio Manual Scenario Run Preview.
10. Redacted Scenario Run Evidence Bundles.
11. Offline Evidence Replay and integrity inspection.

Customer complaint and ecommerce refund are the canonical executable demos.
Renewal churn remains contract-only and is not compile- or run-enabled.

## Explicit Exclusions

- production Runtime Adapter;
- distributed Orchestrator, multi-process coordination, or durable queues;
- Snapshot / Resume or cancellation;
- persistent Audit, Evidence storage, run history, or remote synchronization;
- arbitrary Scenario Plan Authoring;
- real customer adapters, data, SOP, or business rules;
- real LLM, RAG, or knowledge base integration;
- real write, external, financial, or approval side effects;
- multi-tenant identity, authorization, or administration systems;
- production certification or production readiness;
- npm publication.

## Known Limitations

- The demo Engine and Adapter are in-memory and single-process.
- Only canonical demo plans, profiles, cases, handlers, and markers are allowed.
- Renewal churn is contract-only.
- Evidence integrity is deterministic hashing, not a trusted digital signature
  or durable Audit store.
- Runtime execution is not production-hardened, distributed, resumable, or
  persistent.
